# Harness

## Purpose

The harness is the user's local interface to their assistant.

The design is terminal first, inspired by Claude Code and OpenCode.

## Responsibilities

- TUI interface
- local machine access
- command execution
- file interaction
- context collection
- assistant interaction

## Initial Provider

The first integration targets DeepSeek Harness.

waïsp should add a collaboration layer without rebuilding the harness itself.

Future providers can be supported through adapters.
