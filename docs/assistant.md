# Personal Assistant

## Identity

waïsp follows:

```
One person = One assistant
```

The assistant represents the user inside the organization.

## Personal Context

The assistant maintains:

- preferences
- language
- habits
- private knowledge
- personal history

## Responsibilities

- understand user intent
- execute actions
- communicate with other assistants
- use company context
- coordinate work

The assistant combines personal memory with authorized company knowledge.
