# Company Brain

## Purpose

The Company Brain is the self-hosted intelligence server of an organization.

One company owns one Brain.

## Responsibilities

- users and assistants registry
- domain management
- permission management
- A2A routing
- conversation history
- audit logs
- enterprise knowledge
- RAG system

## Knowledge

The Brain contains one centralized RAG system.

Access is controlled by:

- user permissions
- domain membership
- team access
- project rules

Knowledge is filtered during retrieval, not duplicated per domain.

## Deployment

Initial target:
- LAN deployment

Future:
- internet accessible enterprise server
